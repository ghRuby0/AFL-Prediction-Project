# AFL-Prediction-Project
An attempt to employ pandas-native machine learning frameworks to predict AFL match results using anonymised relative scoring
### Overview
A small-scale project intended to practice my own acuity. Employs the pandas library primarily, however I may repeat the project using Apache PySpark at a later date. Involves exploratory machine learning, direct ML predictive implementation, but mainly exists as a vessel for trying out statistical techniques, as well as optimisation. 
### Data Attribution
All data used (as of this commit) is taken from Wheelo Ratings public AFL match stats database. Relevant links are in the script, and will be removed at request from the providers.
